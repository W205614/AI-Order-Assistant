## 发布与适用边界

最终发布提交由 `v0.1.0` 标签固定；对应的 [CI](https://github.com/W205614/AI-Order-Assistant/actions/workflows/ci.yml) 和 [安全工作流](https://github.com/W205614/AI-Order-Assistant/actions/workflows/security.yml) 必须完成后才正式发布。Release 先创建草稿，核对同一提交、说明及附件，再转为正式版本；源码归档由 GitHub 生成。

推送分支与标签只触发 CI/安全验证；真实模型评测仅 `workflow_dispatch`。本轮不部署生产、不改变公开范围，也不发布 Packages。Packages 清单读取返回 HTTP 403，未扩大令牌权限，不能据此断言账号下不存在包。

微信支付/退款/对账、阿里云短信/OSS、高德及云数据库未在本轮调用；真实模型使用独立预算的隔离环境，本地模拟和受控 HTTP 验证不代表真实渠道验收。启用正式服务前仍需完成商户授权、真实回调、设备测试、告警收件、有效备份及独立恢复等准入事项。
