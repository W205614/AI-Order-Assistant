# v0.1.1 修复检查 — 2026-11-09

本次面向个人学习与本地多角色演示，检查 Agent 工具调用、校园报价与结算、售后及套餐输入边界，以及源码发布与许可对应关系。没有扩展产品范围、变更依赖或新增数据库迁移，继续使用 Flyway V9。

## 修复及复现

| 问题 | 原行为及条件 | 修复后 |
|---|---|---|
| Agent 工具时限传递 | `AGENT_TOTAL_TIMEOUT=5`、上游剩余 35 秒时，显式工具 deadline 覆盖已收紧预算，Java 客户端仍可读等待 30 秒；校园工具也未使用 `JAVA_TIMEOUT` | 显式 deadline 与当前预算取较小值，Java 请求头传有效截止时间，校园工具使用配置的 Java 超时；过期后不发起工具请求 |
| 售后空元素 | 有权顾客对已支付订单提交 `items:[null]`，进入元素访问时返回 500 | 按既有输入错误契约拒绝，不创建售后、不改变库存或订单单元 |
| 套餐空元素 | 店主提交 `components:[null]`，进入元素访问时返回 500 | 按既有输入错误契约拒绝，不创建套餐或组件 |

Agent 回归使用固定时钟及 HTTP MockTransport，只隔离网络边界，运行真实预算、Java 客户端及校园工具代码，检查实际请求头、传输超时和未派发行为。四个新增测试先失败，再修复通过。Java 回归使用独立 Testcontainers MySQL 和合成账号，经真实 HTTP 控制器验证状态码、错误类型及数据库无写入。
