## 复验结果

使用独立的 MySQL、Redis 和合成账号，请求在 30 元内推荐主食与饮品，包含打包费和配送费，只查看方案。Gateway 返回 HTTP 200，`gpt-6-luna` 调用 `recommend_campus_meal`，Java 返回跨店候选，推荐方案含费合计 26.50 元。

- 6 项断言通过，覆盖真实模型用量、完整响应、Java 推荐工具、返回核价候选、购物车无写入和订单无写入。
- Redis 账本记录 1 次模型请求，使用 9,180／20,000 保守预算单位。模型接口返回 1,427 输入 token 和 31 输出 token。预算单位按请求字节数及预留输出额度计算。
- 本次覆盖一个只读推荐场景。查券、同名澄清、过敏和模拟支付等流程的验证范围见[校园工作流验收](2026-11-22-campus-workflow.md)。
