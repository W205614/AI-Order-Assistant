验收过程中修复了菜单请求乱序重复展示、JSON 小数表示误触发重新报价、菜单读取补建 SKU 导致锁竞争、首次购物车缺失行间隙锁导致不同顾客死锁等问题。修复保留原延迟门槛和业务断言，没有添加重试掩盖并发失败。

镜像通过仓库 Dockerfile 从源码构建，并生成 SBOM；构建复用了导入的本机 Maven 缓存，不是空缓存或完全离线构建。首次验收时原镜像保留 `before-campus-20261015` 标签；后续复核已将旧镜像归档校验后删除标签及镜像。数据库备份、归档与 Git bundle 保存在本机 `.local`，不入库。

本机缓存的 curl 系统包最初存在两项可修复发现，已通过命名的 `runtime` 阶段刷新到修复版本并复扫；更新前后应用 JAR SHA-256 相同，详见结果 JSON。以后刷新系统包可使用 `--no-cache-filter runtime`，不依赖未命名阶段的内部编号。

新增校园协议的真实提供商对话尚未端到端验证；已验证固定工具边界、真实 Java 报价和无 Agent 手动流程。真实支付、商户资金结算、公网 TLS、长期 SLO、最大容量、地图和自动派单不在本次已验证范围。远端检查须以最终交付提交对应的 Actions 结果为准。
