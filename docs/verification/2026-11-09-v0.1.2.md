# v0.1.2 发布前验证

日期：2026-11-09（Asia/Shanghai）。本记录是最终源码提交前的本地事实；CI、正式发布、包回读和日常升级结果在同版本 Release 说明与本机维护记录中追加，不预写成功。

## 修复范围

- 校园 Agent 的购物车工具拒绝非对象 JSON 后，审计记录仍对参数调用 `get`，导致请求抛出异常。现在只对已成功验证的购物车调用记录商品字段，非法输入保持 `degraded / invalid_tool_arguments`，不调用 Java 写入。
- 商家修改为隔夜营业后，已有预约可能跨越中间的休息时间而两个端点均通过校验。现在校验完整连续营业窗口，保留全天营业、合法跨午夜及预约恰好结束于关门时刻的语义。
- 新增应用薄 JAR 和自身源码的 Maven Packages 发布入口，按已验收候选的源码及摘要发包，不重建、不覆盖版本，下载重定向不转发鉴权头。为同一已验收候选的本机升级支持完整本地镜像 ID，备份及独立恢复门禁保持。
- 修正实际 OpenAI SDK 许可说明；区分源码、应用 JAR、Maven 薄 JAR 和容器基础层的分发材料。未增加业务功能、数据库迁移或依赖版本。

## 运行与分发边界

项目保持个人学习、本地多角色演示及模拟支付定位。真实微信资金、短信、OSS、高德、云和生产验收不属于本轮承诺。新版本不改变长期禁用自动备份策略；本轮升级恢复材料单独存放并保留，不作为已启用日常自动备份的证明。日常实例原为停止状态，完成必要升级验收后恢复停止。

目标分发为 `v0.1.2` Release 源码、Java 应用包，以及 Maven `com.ai:assistant-gateway:0.1.2`。必要许可材料随实际应用包核验，尚未公开的制品不算已发布；容器仅用于本机验证与升级，不公开分发 OS/JRE 基础层。原公开版本不改写。
